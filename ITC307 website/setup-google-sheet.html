Google Sheet Setup Helper

Follow these steps to set up your Google Sheet for the Fiji Task Marketplace

Your Google Sheet: View Your Sheet
1
Create Bids Sheet

Your current sheet has tasks. You need to add a second sheet for bids.

Sheet Name: Bids
Headers (Row 1):
Task ID | Bidder Name | Amount | Message | Estimated Time | Status
2
Share Your Sheet

Make sure your Google Sheet is accessible to the website.

  • Click "Share" in the top right of your Google Sheet
  • Click "Change to anyone with the link"
  • Set permission to "Editor"
  • Copy the sharing link
3
Get API Key

You need a Google Sheets API key to connect your website to the sheet.

Go to Google Cloud Console
• Create a new project
• Enable Google Sheets API
• Create API credentials
• Copy the API key
4
Update Website

Add your API key to the website configuration.

// Open js/google-sheets-api.js
// Find line 4: this.apiKey = '';
// Replace with: this.apiKey = 'YOUR_API_KEY_HERE';
5
Test Integration

Verify everything is working correctly.
